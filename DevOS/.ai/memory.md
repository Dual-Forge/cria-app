# AI MEMORY

## Objetivo

Registrar decisões permanentes tomadas durante o desenvolvimento.

Este documento funciona como memória de longo prazo da IA.

Não registrar tarefas.

Não registrar progresso.

Não registrar alterações pequenas.

Registrar apenas decisões que impactam o projeto.

---

# Estrutura

Cada registro deve conter:

Data

Título

Descrição

Motivo

Impacto

---

# Memórias

## Exemplo

### 2026-07-20

Título

Padronização de Soft Delete.

Descrição

Todas as entidades utilizarão Soft Delete.

Motivo

Evitar perda definitiva de dados.

Impacto

Todas as tabelas deverão possuir archived_at.
