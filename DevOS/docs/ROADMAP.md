# MVP (Versão Inicial)

## Objetivos da Versão
Entrega funcional das rotinas de saúde e lista de presentes inteligente, garantindo o recebimento de doações em Pix.

## Funcionalidades Planejadas
- [x] Autenticação de pais.
- [x] Cadastro de perfis de famílias e bebês.
- [x] Acompanhamento do bebê (frequência cardíaca, contagem de chutes).
- [x] Integração com IA para geração de dicas semanais e consultoria de enxoval.
- [x] Extração automatizada de dados de links de produtos via IA.
- [x] Vitrine pública para visualização dos presentes por terceiros.
- [x] Checkout e pagamento de contribuições via Mercado Pago (Pix).
