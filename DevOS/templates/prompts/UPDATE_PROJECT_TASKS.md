# UPDATE_PROJECT_TASKS

## Objetivo

Manter PROJECT_TASKS.md atualizado.

Este documento representa a lista oficial de trabalho do projeto.

Todas as tarefas devem ser derivadas do PROJECT_BRIEF ou das decisões aprovadas pelo usuário.

---

# Entrada

Leia:

PROJECT_BRIEF.md

PROJECT_STATUS.md

Todo o projeto.

---

# Organização

As tarefas devem ser organizadas em:

## TODO

Ainda não iniciadas.

## EM ANDAMENTO

Atualmente sendo desenvolvidas.

## CONCLUÍDO

Finalizadas.

---

# Regras

Nunca criar tarefas fora do escopo.

Nunca remover tarefas concluídas.

Mover tarefas entre as seções conforme o desenvolvimento.

Quebre funcionalidades grandes em tarefas menores quando necessário.

As tarefas devem ser objetivas.

Cada tarefa deve representar uma unidade clara de trabalho.

---

# Qualidade

Priorize tarefas do MVP.

As tarefas devem seguir a ordem lógica de desenvolvimento.

Evite tarefas genéricas.

Exemplo ruim:

"Fazer sistema."

Exemplo bom:

"Criar CRUD de Empresas."

---

# Saída

Atualize apenas PROJECT_TASKS.md.

Ao finalizar informe:

- tarefas adicionadas;
- tarefas movidas;
- tarefas concluídas;
- tarefas bloqueadas.
