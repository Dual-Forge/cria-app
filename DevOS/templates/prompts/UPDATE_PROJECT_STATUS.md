# UPDATE_PROJECT_STATUS

## Objetivo

Atualizar exclusivamente o arquivo PROJECT_STATUS.md.

Este documento representa o estado atual do projeto.

Ele deve permitir que qualquer pessoa compreenda o andamento do projeto em menos de dois minutos.

---

# Entrada

Leia:

PROJECT_BRIEF.md

PROJECT_TASKS.md

Todo o projeto.

---

# Atualize

- Sprint atual
- Status geral
- Progresso geral
- Última tarefa concluída
- Próxima tarefa
- Bloqueios
- Última atualização

---

# Regras

Não invente progresso.

Não estime porcentagens sem evidências.

Caso não seja possível determinar alguma informação, escreva:

"Não identificado."

Nunca altere funcionalidades.

Nunca altere escopo.

Atualize somente o status.

---

# Objetivo final

Ao abrir PROJECT_STATUS.md qualquer desenvolvedor deve entender imediatamente:

Onde o projeto está.

O que foi concluído.

O que está sendo desenvolvido.

Qual será o próximo passo.
