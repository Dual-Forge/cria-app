# Audio Assets

## heartbeat.mp3
- **Frequência Base**: 120 BPM
- **Duração**: ~2-3 segundos (uma batida completa)
- **Formato**: MP3
- **Uso**: Reprodução dinâmica de batimentos cardíacos com playback rate ajustável

### Especificações Técnicas
- Sample Rate: 44100 Hz
- Bitrate: 128 kbps (mínimo)
- Canais: Mono ou Estéreo
- Codec: MP3

### Como Gerar
Se você não tiver um arquivo de áudio, pode gerar usando ferramentas como:
1. **Audacity** (gratuito): Gerar tom de 120 BPM
2. **Online Tools**: Procurar por "heartbeat sound generator"
3. **Royalty-free**: Baixar de sites como Freesound.org

### Integração
O arquivo será reproduzido com playback rate dinâmico:
- BPM 60 → playback rate 0.5x (metade da velocidade)
- BPM 120 → playback rate 1.0x (velocidade normal)
- BPM 180 → playback rate 1.5x (1.5x mais rápido)

**Nota**: O playback rate é limitado entre 0.5x e 2.0x para segurança.
